# **v2t-tg Bot** #
**voice to text*

Это бот для расшировки ваших голосовых/видео сообщений.  В основе лежит **faster_whisper** для перевода **из аудио в текст**.

Также использована Локальная модель **unsloth/Qwen3.5-4B-GGUF** для доробтки текста из whisper-а

Вы просто отправляете боту голосовое или видео сообщение и вам выведется текст. Также есть **функция пересказа**, основанная на **nvidia/nemotron-3-super-120b-a12b:free** 

Самое главное, что этот проект **АБСОЛЮТНО БЕСПЛАТНЫЙ**

Я просто надеюсь что его будут **локально использовать**. Ну, впалне либо один человек либо небольшое количество, т.к я хз кто может себе в 2026 позволить арендовать серв с такими характеристиками и не иметь никакой выгоды с этого.

## **Подробнее как это работает** ##

Здесь используется **faster_whisper** (я рекмоендую модель *medium*), т.к она гораздо более оптимизированная и вместо с квантованием занимает менее 2 гигов VRAM

требования разынх моделей(указано c квантованием **int8_float16**):
| whisper | VRAM, ГБ | 
| :--- | :---: | 
| tiny | ~0.5 | 
| base | ~1 | 
| small | ~1.5 | 
| medium | ~2 | 
| large | ~5 | 

После расшифровки текста, модель unsloth/Qwen3.5-4B-GGUF используется для доработки текста. Она ставит пунктуацию и исправляет ошибки в тексте. занимает **~3.5 гига VRAM**.

Как работает пересказ? Очень просто: по OpenRouter api отправляется к nvidia/nemotron-3-super-120b-a12b:free промпт с уже обработанным текстом. 

## Производительность ##

Я использую ноутбук с RTX3070ti на 8 гигов VRAM. Он переводил сообщение **длиной в 7 минут за 44 секунды** (я считал по логам aiograma) Это, если что,   время полного цикла, т.е расшифровка + дороботка.
Самое смешное, что расшифровка в тг премиум не справилась с этим же гс хахахах

Это хороший и показательный результат , как мне кажется.

## **Как запустить?** ##

1. инициализировать uv - `uv init`
2. Установите зависимости: `uv add -r requirements.txt`
3. Зайдите в бот https://web.telegram.org/k/#@BotFather и создайте нового бота. Скопируйте токен бота.
4. Заригестрируйтесь на **Hugging Face** и получите API ключи: [https://huggingface.co/](https://huggingface.co/)
5. Также зарегистрируйтесь и получите API ключи в **OpenRouter**: https://openrouter.ai/
6. Запустите **start.py**, введите API ключи, Прокси и настройте так, как вам надо.  
7. Запустите **run.sh** для запуска бота.
