# **v2t-tg Bot** #
**voice to text**

**Пожалуйста**, прочитайте README полностью, чтобы избежать недопонимания. 

Это бот для расшифровки ваших голосовых/видео сообщений, и даже просто видео и аудио. В основе лежит **faster_whisper** для перевода **из аудио в текст**.

Также использована локальная модель **unsloth/Qwen3.5-4B-GGUF** для доработки текста из whisper-а

Вы просто отправляете боту голосовое или видео сообщение и вам выведется текст. Также есть **функция пересказа**, основанная на **nvidia/nemotron-3-super-120b-a12b:free** 

Самое главное, что этот проект **АБСОЛЮТНО БЕСПЛАТНЫЙ**

Я просто надеюсь, что его будут **локально использовать**. Ну, в плане либо один человек, либо небольшое количество, т.к. я хз, кто может себе в 2026 позволить арендовать сервер с такими характеристиками и не иметь никакой выгоды с этого.

## **Подробнее как это работает** ##

Перед запуском надо собрать все API-ключи и прокси (указано какие в разделе **Как запустить?**). После запустите start.py. В start.py следующие настройки:

* **API** ключи и токены (тг, openrouter, HuggingFace)
* Какую **модель для пересказа** использовать
* **Прокси**
* Модель *whisper* (какую выбрать и как выбрать написано ниже)
* Использовать **GPU или CPU**
* Какую модель *whisper* использовать
* Использовать ли **qwen (локальная обратботка), только whisper или по API (OpenRouter)**
* Если **qwen/API**, то какую *модель* использовать
* Предоставлять результаты **сразу или по отдельности** (про это написано ниже, второй абзац после таблицы)
* Какой вид доступа: **публичный или белый список**
* Если белый список, то **какие пользователи имеют доступ** (указать их **id**)

Здесь используется **faster_whisper** для расшифровки аудио.

Требования разных моделей (указано с квантованием **int8_float16**):
| whisper | VRAM, ГБ | Физический вес файла | параметры | 
| :--- | :---: | :---: | :---: |
| tiny | ~0,3–0,4 | ~80 МБ| 39M |
| base | ~0,4–0,5  | ~150 МБ | 74M |
| small | ~0,6–0,8  | ~490 МБ |244M |
| medium |~1,2–1,5  | 1,53 ГБ | 769M |
| large-v3 | ~2,0–2,5 | ~3,1 ГБ| 1550M |
| large-v3-turbo | ~1,2–1,6 | 1,62 ГБ | 809M |

(*лично я использую модель large-v3-turbo, и вам советую*)

После расшифровки текста, модель *unsloth/Qwen3.5-4B-GGUF* используется для доработки текста. Она ставит пунктуацию и исправляет ошибки в тексте. Занимает **~3.5 ГБ VRAM**.

Но также есть вариант с моделью пост-обработки по **API** через *OpenRouter*. Я *лично использую nvidia/nemotron-3-super-120b-a12b:free*. Это не будет тратить VRAM, но пост-обработка будет **значительно медленнее**.

Также есть режим раздельной отправки текста. Сначала отправляется сырой текст, а потом, когда готов уже обработанный, он заменяется тем, который был изначально. **Это никак не влияет на производительность**, но делает вид, что бот работает быстрее. 

В сумме, во время работы у меня занимает обычно (с моделью *qwen3.5-4b-q5* и *large-v3-turbo*) **4610 МБ видеопамяти**. Но, с учётом других приложений получается **6 гигов из 8**. 

Как работает пересказ? Очень просто: через OpenRouter API отправляется к nvidia/nemotron-3-super-120b-a12b:free промпт с уже обработанным текстом. 



## Производительность ##

Я использую ноутбук с RTX 3070 Ti на 8 гигов VRAM. Он переводил сообщение **длиной в 7 минут за 44 секунды** (На модели *medium*) (я считал по логам aiogram). А на модели *large-v3-turbo* Это же гс у меня обработалось за **22 секунды**. Это, если что, время полного цикла, т.е расшифровка + доработка.

Самое смешное, что расшифровка в тг премиум не справилась с этим же гс хахахах

Это хороший и показательный результат, как мне кажется.

Также есть поддержка *qwen3.5-2b-q5*, она гораздо быстрее, около **160 токенов в секунду** по сравнению с *qwen3.5-4b-q4* (**82 токена в секунду**) и *qwen3.5-4b-q5* (**72 токена в секунду**). В итоге это расшифровка с *qwen3.5-2b-q5* на **27 процентов быстрее**. Но qwen на 2 миллиарда параметров **гораздо менее качественная**, так что выбирайте сами.

## **Как запустить?** ##

1. Установите зависимости: `uv sync`
2. Зайдите в бот [**BotFather**](https://web.telegram.org/k/#@BotFather) и создайте нового бота. Скопируйте токен бота.
3. Зарегистрируйтесь на [**Hugging Face**](https://huggingface.co/) и получите API ключи.
4. Также зарегистрируйтесь и получите API ключи в [**OpenRouter**](https://openrouter.ai/).
5. Запустите **start.py**, введите API ключи, Прокси и настройте так, как вам надо.  
6. Запустите **run.sh** для запуска бота.

**также, можно использовать `run.sh main.py` чтобы запустить отдельно расшифровку, без бота в телеграмме*
